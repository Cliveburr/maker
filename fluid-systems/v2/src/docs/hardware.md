## FreeCAD: macro de cavidade para porca M2

Criei um macro em freecad_macros/m2_nut_pocket_macro.py que gera um bloco-teste com três cavidades
hexagonais para porca M2 (folgas 0.0 / +0.1 / +0.2 mm).

Como usar:
- Abra o FreeCAD (GUI).
- `Macro → Execute` e selecione `m2_nut_pocket_macro.py`, ou no console Python execute:
```
exec(open(r"d:\\GitTemp\\FluidSystem\\freecad_macros\\m2_nut_pocket_macro.py").read())
```
- O documento `M2_Nut_Pockets` será criado; imprima o bloco-teste e escolha a folga que funciona no seu processo.

Parâmetros que você pode editar no arquivo: `AF_nominal`, `tolerances`, `hole_diameter`, `pocket_depth`.



Stepper motor: 28BYJ-48 5V DC .. com placa de controle pinos VDD-in1-in2-in3-in4-GND
